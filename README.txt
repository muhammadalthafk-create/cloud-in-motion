CLOUD IN MOTION - Live Parcel Tracker website

HOW TO OPEN
1. Unzip this file (right-click, then Extract All).
2. Open the folder "parcel-tracker".
3. Double-click index.html. It opens in your browser. Use Chrome, and stay online so the fonts load.

WHAT IS INSIDE
- index.html : the whole website (home page, Register page, Live Parcel Tracker)

NOTES
- The Register form is front end only. Nothing is saved or sent.
- Scans in the tracker are saved only in your own browser for now.
- Next step: connect Firebase so accounts and scans live in the cloud.
